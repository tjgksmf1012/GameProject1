# 「일섬 ISSEN」 게임 컨셉

## 1. 핵심 판타지

> **몰려드는 적을 단 한 번의 칼질로 전부 베어버린다.**

플레이어가 얻고 싶은 감정은 "잘 싸웠다"가 아니라 **"내가 방금 뭘 한 거지"** 입니다.
한 번의 입력이 화면 전체를 바꾸는 순간, 그 하나에 모든 설계를 겁니다.

## 2. 조작

```
왼쪽 스틱 / WASD  →  이동
버튼 1개 (A / 좌클릭 / 스페이스)  →  발도(拔刀)
```

**끝입니다.** 점프 없음. 회피 없음. 콤보 없음. 메뉴 없음.

이게 부스에서 결정적입니다. 스태프가 한 명 한 명 설명할 수 없는 환경에서, 컨트롤러를 쥐자마자
아무 버튼이나 눌러도 즉시 칼이 나가고 적이 터집니다. 튜토리얼 텍스트를 읽는 사람은 없습니다.

## 3. 코어 루프 (1사이클 8~15초)

```
① 유인    적이 사방에서 느리게, 예측 가능하게 몰려온다
             ↓
② 모으기  플레이어가 이동하며 적을 한 덩어리로 뭉친다  ← 여기가 실력
             ↓
③ 발도    버튼 1회. 범위 안의 적 전원 즉사
             ↓
④ 경직    발도 후 0.8초 쿨다운. 유일한 위험 구간
             ↓
⑤ 상승    적 밀도/속도가 오른다 → ①로
```

### 점수 공식이 게임 전체를 규정합니다

```
1회 발도 점수 = (동시 처치 수)²  ×  콤보 배율
```

- 1마리씩 10번 벰 → **10점**
- 10마리를 한 번에 벰 → **100점**

제곱 스케일이 전부입니다. 이 한 줄이 "참는 게임"을 만듭니다.
고수는 칼을 뽑지 않습니다. 적이 코앞까지 올 때까지 참고, 유인하고, 뭉치고, 그리고 한 번.

> **관전 재미의 정체**: 참는 긴장감입니다.
> 뒤에서 보는 사람이 "지금! 지금 눌러!" 하고 소리치게 되는 순간 — 그게 부스에서 줄을 만듭니다.
> 화려한 이펙트는 그 다음 문제입니다.

## 4. 실력 곡선 — 초보와 고수가 같은 게임을 다르게 본다

| | 초보 (첫 30초) | 중급 (3분째) | 고수 (10시간째) |
|---|---|---|---|
| 행동 | 보이는 대로 마구 누름 | 3~5마리 모아서 벰 | 20마리 이상 유인해 한 방 |
| 1회 처치 | 1~2마리 | 5~8마리 | 20~40마리 |
| 화면 | 적당히 터짐, 재밌음 | 백색 섬광 + 슬로우 | 화면이 갈라짐 |
| 감정 | "오 이거 시원한데" | "더 모을 수 있겠는데?" | "완벽한 한 방" |

**핵심**: 초보도 즉시 재밌고 죽지 않습니다. 그런데 화면을 보면 자기가 못하고 있다는 걸 압니다 —
왜냐하면 옆 랭킹 보드의 1등은 자기 점수의 20배거든요. 이 격차가 "한 판 더"를 만듭니다.

## 5. 연출 — 동시 처치 수에 따른 단계적 폭발

연출은 **오직 동시 처치 수 하나**로 결정됩니다. 플레이어가 인과관계를 즉시 학습합니다.

| 동시 처치 | 연출 |
|---|---|
| 1~4 | 참격선 1줄, 적이 2조각으로 분리, 붉은 파티클 |
| 5~9 | **히트스톱 0.15초** + 화면 백색 섬광 + 짧은 슬로우모션 |
| 10~19 | 카메라 줌아웃 + 배경 무채색화 + 화면 관통하는 붉은 궤적선 |
| 20+ | **「일섬」** — 화면이 대각선으로 갈라져 어긋났다가 다시 붙음. 모든 적이 동시에 분리되어 흩날림. 0.5초 정적 후 굉음 |

### 게임필 체크리스트 (M2에서 이것만 판다)

- [ ] 히트스톱 — 벤 순간 프레임을 실제로 멈춘다 (0.08~0.2초, 처치 수 비례)
- [ ] 카메라 — 발도 방향으로 살짝 밀리고 돌아온다. 큰 처치엔 줌아웃
- [ ] 파편 — 적은 반드시 물리 파편 2조각으로 분리 (터지지 않고 **갈라진다**)
- [ ] 잔상 — 칼 궤적이 0.3초 남는다. 이게 스크린샷을 만든다
- [ ] 진동 — 처치 수 비례 컨트롤러 진동
- [ ] 정적 — 큰 처치 직후 **모든 소리를 0.3초 끈다**. 시끄러운 홀에서도 이건 전달된다

> 시끄러운 전시장(85dB+)에서 사운드는 거의 죽습니다.
> **모든 피드백은 시각적으로 중복 구현**해야 합니다. 사운드는 보너스로 취급하세요.

## 6. 아트 디렉션 — 저비용 고임팩트

**3색 팔레트: 먹빛 검정 / 흰색 / 주홍.**

- 배경: 단색 그라데이션 + 수묵 텍스처 한 장. 지오메트리 최소
- 캐릭터/적: **실루엣**. 디테일 없음. 아웃라인 셰이더로 형태만
- 액센트: 주홍색은 오직 두 곳에만 — 적의 공격 예고, 그리고 피

### 이 방향을 고른 세 가지 실무적 이유

1. **아트 리소스가 거의 안 듭니다.** 3D 모델러 없이 프로그래머 + 테크니컬 아티스트만으로 완성 가능합니다. 3.5개월 일정에서 이건 타협이 아니라 생존 조건입니다.
2. **부스에서 압도적으로 잘 읽힙니다.** 최대 명암 대비 = 5m 밖 어깨너머에서도 무슨 일이 벌어지는지 보입니다. 전시장 조명은 밝고 모니터는 작습니다.
3. **스크린샷이 그 자체로 스타일이 됩니다.** 스팀 페이지 전환율은 첫 스크린샷 4장이 결정합니다. 저예산 3D 리얼리즘은 절대 이기지 못하지만, 강한 그래픽 스타일은 예산과 무관하게 이깁니다.

**카메라: 쿼터뷰(아이소메트릭) 3D.** 적이 뭉치는 형태가 가장 잘 읽히고, 관전자도 전체 판을 봅니다.

## 7. 적 설계 — 뭉치기가 재미의 전부

적 AI에 개발 시간을 가장 많이 써야 합니다. "잘 뭉치는" 적이 이 게임의 심장입니다.

| 적 | 역할 | 행동 |
|---|---|---|
| **잡졸** | 물량 | 플레이어를 직선으로 천천히 추격. 서로 겹치지 않고 뭉친다 (플로킹) |
| **돌격병** | 압박 | 주홍 섬광 후 직선 돌진. 유인 미끼로 쓰기 좋다 |
| **방패병** | 제약 | 정면 발도 무효. 뒤로 돌아가야 함 → 플레이어 동선을 강제 |
| **폭발체** | 보너스 | 베면 주변 적을 끌어당긴다 → 연쇄 뭉치기. 고수의 도구 |

> **폭발체가 설계의 열쇠입니다.** 플레이어가 "적을 능동적으로 모을 수 있는 도구"를 가지면
> 뭉치기가 우연이 아니라 **계획**이 됩니다. 이게 스킬 실링을 만듭니다.

## 8. 이 게임이 실패할 수 있는 지점

정직하게 적어둡니다. M1 프로토타입에서 이걸 검증하지 못하면 피벗해야 합니다.

1. **"참기"가 지루할 수 있다.** 모으는 8초가 재미없으면 게임 전체가 무너집니다.
   → 대응: 모으는 동안에도 적을 스치듯 흘리는 회피 쾌감을 넣습니다. 아슬아슬함이 채워줘야 합니다.
2. **적 뭉치기 AI가 어렵다.** 적이 예쁘게 안 뭉치면 실력이 개입할 여지가 사라집니다.
   → 대응: 플로킹 파라미터 튜닝에 M1의 절반을 씁니다.
3. **타이밍 게임 진입장벽.** 못하는 사람이 아예 못 하면 부스에서 최악입니다.
   → 대응: 발도 판정을 관대하게, 실패 페널티를 약하게. 부스 빌드는 **죽어도 5초 뒤 부활**(콤보만 리셋).
