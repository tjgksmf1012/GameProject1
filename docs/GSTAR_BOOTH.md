# 부스 빌드 메모 (코옵 기준)

> 컨셉이 확정되면 다시 씁니다. 지금은 **코옵으로 방향이 바뀌면서 달라지는 것**만 적어둡니다.

## 코옵이 부스에서 유리한 이유

싱글 게임을 부스에 놓으면 한 명이 하고 여러 명이 구경합니다.
**코옵을 놓으면 네 명이 옆자리에 앉아 서로에게 소리를 지릅니다.**

- 근접 음성 채팅이 **필요 없습니다.** 실제로 옆에 앉아 있으니까요. 온라인보다 오히려 낫습니다
- 부스 자체가 콘텐츠가 됩니다. 네 명이 동시에 비명 지르는 소리가 통로까지 들립니다
- 지나가던 사람이 멈추는 이유는 화면이 아니라 **소리와 사람**입니다
- 4인 = 일행 단위 유입. 친구끼리 온 방문객을 통째로 잡습니다
- 스팀에서도 4인 코옵은 1명이 사면 3명이 더 삽니다. **바이럴 계수가 판매 계수**입니다

## 달라지는 것

| 항목 | 싱글 기준 | 코옵 기준 |
|---|---|---|
| PC | 1대 | **4대 + 호스트** (부스 비용의 핵심 변수) |
| 좌석 | 1석 | 4석, 서로 얼굴이 보이게 **ㄷ자 배치** |
| 모니터 | 1대 | 4대 + **관전용 대형 1대** (통로 방향) |
| 세션 | 3분 | **5~7분** (코옵은 붙는 데 시간이 걸림) |
| 회전 | 1명씩 | 4명씩 — 오히려 시간당 인원이 늘어납니다 |

> **관전용 대형 모니터**가 코옵 부스의 핵심 장비입니다.
> 네 명의 화면 중 가장 난장판인 화면을 자동으로 띄우거나, 전체를 조망하는 카메라를 걸어두세요.

## 예산이 부족하면

4대가 부담되면 **2인 협동으로 축소**해도 이 기획들은 전부 성립합니다.
김장은 둘이서 하면 오히려 더 정신없고, 거신은 팔다리를 두 명이 나눠 맡으면 됩니다.
2대 + 관전 모니터 1대가 현실적인 최소 구성입니다.

## 검증 지표 (컨셉 무관, 이것만 봅니다)

1. 컨트롤러를 쥐고 **첫 웃음이 터질 때까지** 걸린 시간 → 목표 60초 이내
2. 한 세션에서 **팀원끼리 소리를 지른 횟수** → 이게 0이면 코옵으로 실패입니다
3. 끝나고 **"한 판 더"** 하는 비율 → 목표 50% 이상

3번이 30% 아래면 콘텐츠를 늘리지 말고 **물리 튜닝을 더 파세요.**
