# 지스타 부스 빌드 & 현장 운영 설계

부스 게임과 스팀 게임은 **다른 물건**입니다. 같은 빌드를 그냥 들고 가면 반드시 실패합니다.
여기 적힌 항목들은 게임성과 무관해 보이지만, 현장에서 승패를 가르는 건 대부분 이쪽입니다.

## 1. 부스 빌드가 반드시 만족해야 할 조건

### 세션 설계

| 항목 | 스펙 | 이유 |
|---|---|---|
| 1회 플레이 | **3분 고정 타임어택** | 시간당 회전율 예측 가능. 줄이 안 막힌다 |
| 사망 처리 | **5초 뒤 자동 부활**, 콤보 배율만 리셋 | "1분 만에 죽고 끝"은 부스 최악의 경험 |
| 시작 | 아무 버튼 → 즉시 시작 | 메뉴·설정·로딩 화면 전부 제거 |
| 종료 | 점수 → 이름 3글자 → 랭킹 → 자동 리셋 | 다음 사람까지 15초 안에 |
| 무입력 | 30초 무입력 시 **어트랙트 모드** 자동 진입 | 빈 부스가 화면으로 손님을 끈다 |

### 어트랙트 모드 (아무도 안 할 때 나오는 화면)

이게 부스 트래픽의 절반을 만듭니다. 절대 생략하지 마세요.

- AI가 자동 플레이하는 하이라이트 루프 (20마리 이상 처치 장면만 편집)
- 화면 하단에 **조작법 아이콘 2개**만 크게: `[스틱] 이동` `[A] 베기`
- 상단에 오늘의 TOP 5

### 안정성 (타협 불가)

- [ ] **8시간 연속 무크래시.** 크래시 = 그날 부스 종료입니다
- [ ] 크래시 시 자동 재시작 (워치독 프로세스)
- [ ] 컨트롤러 핫플러그 — 뽑았다 꽂아도 즉시 인식
- [ ] 메모리 누수 검증 — 3분 세션 200회 자동 반복 테스트
- [ ] `Alt+Tab`, `Win` 키, 종료 단축키 **전부 차단**. 전체화면 고정
- [ ] 오프라인 동작 — 전시장 네트워크는 반드시 죽습니다. 랭킹은 **로컬 저장** 후 나중에 동기화

## 2. 부스 물리 구성

```
        [세로 모니터: 실시간 랭킹 TOP 10]
                    │
   [플레이 모니터 27" 이상 · 눈높이보다 살짝 아래]
                    │
        [컨트롤러 2개 — 1개는 다음 사람용]
                    │
              (플레이어 1명)
         (뒤에 관전자가 서는 공간)
```

- **모니터는 크고 높게.** 뒤에 선 사람이 어깨너머로 봐야 합니다. 관전자가 다음 플레이어입니다
- **컨트롤러 2개 상시 배치.** 다음 사람이 미리 쥐고 있으면 교대가 5초로 줄어듭니다
- **헤드폰 쓰지 마세요.** 착용/소독 시간이 회전율을 죽이고, 관전자가 소외됩니다. 스피커로 갑니다
- **랭킹 모니터를 통로 쪽으로.** 지나가는 사람이 점수를 보고 멈춰섭니다

## 3. 스팀 전환 설계 — 부스는 위시리스트 수집 장치입니다

부스의 진짜 목적은 재미가 아니라 **위시리스트 등록 수**입니다. 여기서 역산하세요.

- **게임오버 화면 QR을 화면의 1/3 크기로.** 작게 넣으면 아무도 안 찍습니다
- QR 옆 문구: `당신의 기록 ○○위 — 스팀에서 계속하기`. 개인화된 숫자가 전환율을 올립니다
- **최고 기록 클립 자동 저장** → QR로 본인 폰에 전송. 이게 SNS에 올라가면 부스 밖 홍보가 됩니다
- 하루 마감 시 그날 TOP 3 기록 SNS 업로드 → 다음 날 재방문 유도

## 4. 현장 운영

| 항목 | 내용 |
|---|---|
| 스태프 멘트 | **한 문장으로 통일**: "스틱으로 움직이고, 많이 모아서 A 한 번!" 스태프마다 설명이 다르면 안 됩니다 |
| 대기줄 | 대기 중인 사람이 랭킹 모니터를 볼 수 있게 동선 설계 |
| 굿즈 | 스티커면 충분합니다. 단, **QR을 스티커에 인쇄**하세요 |
| 기록 | 시간대별 플레이 수 / 평균 점수 / QR 스캔 수를 수기로라도 집계 → 다음 마케팅의 근거 |
| 예비 | PC 1대, 모니터 1대, 컨트롤러 4개 여분. 무선 컨트롤러는 전시장 전파 간섭으로 자주 끊깁니다 → **유선 권장** |

## 5. 플레이테스트 — 이것만은 반드시

**모르는 사람 대상 테스트를 최소 2회.** 개발팀과 지인은 이미 게임을 알기 때문에 무의미합니다.

측정할 것 — 오직 세 개입니다:

1. **컨트롤러를 쥐고 첫 처치까지 걸린 시간** → 목표 5초 이내
2. **아무 설명 없이 "모아서 한 번에 베면 점수가 크다"를 스스로 깨닫는 데 걸린 시간** → 목표 60초 이내
3. **3분 끝나고 "한 판 더" 하고 싶어하는 비율** → 목표 50% 이상

3번이 30% 아래면 부스에서 줄이 안 섭니다. 그때는 컨텐츠를 늘리지 말고 **게임필을 더 파야** 합니다.
