# 1. 가장 중요한 평가 — 메커니즘 발명이 있다

[SATURATION.md](SATURATION.md)의 결론은 이랬습니다.

```
❌ 소재를 정하고 → 메커니즘을 붙인다
✅ 메커니즘을 발명하고 → 소재는 흔한 걸 쓴다
```

NIGHTSHIFT는 정확히 후자입니다.

| | |
|---|---|
| **소재 (흔함)** | 규칙 대조 판정 + 야간 근무 호러. Papers Please · FNAF · 규칙괴담 — 관객이 문법을 이미 안다 |
| **메커니즘 (발명)** | **수칙 중 일부가 거짓이며, 지키면 죽는다** |

이게 진짜 새로운 축인 이유:

> Papers, Please의 규칙은 부조리하지만 **정직**합니다. 규칙대로 하면 살아남습니다.
> NIGHTSHIFT는 규칙 자체가 거짓말을 합니다.
> 게임의 질문이 **"규칙을 지켰는가"에서 "어떤 규칙을 믿을 것인가"로 바뀝니다.**

MECCHA CHAMELEON이 숨바꼭질(가장 흔한 소재)에 `붓으로 몸을 칠한다`는 메커니즘 하나를 얹어 뚫은 것과
같은 구조입니다. 이 저장소가 찾던 답의 형태가 맞습니다.

# 3. 특히 잘 된 부분

## 3-1. 장르 선택이 이미 절반이다

`호러 히트율 3.2% vs 2D 플랫포머 0.18%` — **17배 차이.**
어떤 게임을 만드느냐보다 어떤 칸에 서느냐가 먼저 결정한다는 걸 정확히 반영했습니다.

## 3-2. 검증된 1인 개발 공식을 그대로 따른다

`단일 메커니즘 + 짧은 분량 + 저가` — The Exit 8, Buckshot Roulette이 증명한 경로입니다.
Buckshot Roulette은 1인·약 2개월·Godot이었습니다. 벤치마크 선택이 현실적입니다.

## 3-3. 공정성 불변식 4개 (F-01)

이게 이 기획서에서 가장 뛰어난 부분입니다.

1. 판정에 필요한 모든 단서는 판정 시점에 화면에 존재
2. 거짓 수칙은 반드시 사전에 반증 가능한 단서를 남긴다
3. 실패 후 3초 리플레이로 놓친 단서를 보여준다
4. 무작위화는 조합·순서에만. 개별 판정은 결정론적

**"속았다"와 "알아챌 수 있었는데 놓쳤다"의 차이가 이 게임의 생사입니다.**
그리고 이걸 자동 테스트로 검증하겠다고 못박은 게 특히 좋습니다.

## 3-4. `systems/`를 노드 비의존으로

1인 + AI 개발에서 가장 중요한 아키텍처 결정이 맞습니다.
AI는 화면을 못 봅니다. 헤드리스 테스트가 가능한 순수 로직 계층이 있어야 검증 루프가 성립합니다.

## 3-5. 스코프 방어 장치

`아트 에셋 필요하면 반려` / `파일 300줄 상한` / `Won't 목록` / `icebox` / `컷 라인 사전 확정`.

> *"AI가 빠르다는 이유로 기능을 늘리는 것이 이 프로젝트 최대 사망 원인이다."*

정확한 진단입니다. 컷 라인을 **밀리기 전에** 정해둔 것도 실무적으로 옳습니다.

# 4. 진짜 리스크 — 문서가 과소평가한 것들

## 🔴 4-1. 발견성이 가장 약한 고리다 (최대 리스크)

문서는 마케팅을 *"무예산"* 으로 잡았습니다. 그런데:

| 사실 | |
|---|---|
| Next Fest 출품작 | 회당 **3,500~4,000개** |
| 스팀 신작 | 하루 **70~80개** |
| 월 $1,000 이상 | **5% 미만** |
| 2025 신작 median 매출 | 약 **$249** |

**위시리스트 7,000은 무예산으로 매우 어려운 숫자입니다.** 그리고 이 게임은 바이럴 계수가 1입니다
(친구를 데려오지 않음). 즉 **발견 경로가 스트리머 하나뿐**이고, 그건 통제 불가능한 변수입니다.

### 제안 A — Steam 페이지를 M3(12월)이 아니라 M1 끝(10월)에 연다

**위시리스트는 시간의 함수입니다.** 페이지가 열려 있는 날부터 쌓입니다.
게임이 완성되기 전에 여는 게 정석이고, 스크린샷 4장과 짧은 GIF만 있으면 열 수 있습니다.
2개월 일찍 열면 Next Fest 진입 시점의 기저 위시리스트가 달라집니다.

### 제안 B — 트레일러 첫 5초를 M2에 만든다

문서는 트레일러를 M3에 두었습니다. 너무 늦습니다.
**첫 5초에 "수칙이 거짓말을 한다"가 보이지 않으면 이 게임은 Papers Please 아류로 스크롤됩니다.**
버티컬 슬라이스가 나오는 M2에 15초 컷을 만들어 반응을 먼저 테스트하세요. 실패해도 그때는 고칠 수 있습니다.

## 🟠 4-2. 2~3시간은 가장 애매한 분량이다

| 분량 | 포지션 |
|---|---|
| 1시간 | "짧아서 좋다" — The Exit 8이 이 칸에서 이겼다 |
| **2~3시간** | **어느 쪽도 아니다** |
| 6시간+ | "분량 있다" — Papers, Please |

The Exit 8이 스포일러 붕괴를 견딘 이유는 **애초에 1시간짜리라 상관없었기** 때문입니다.
규칙 게임은 정답이 유출되면 가치가 급락하는데, 3시간짜리는 유출 노출 시간이 3배입니다.

**선택지 둘 중 하나로 정하는 걸 권합니다:**
- **A.** 1~1.5시간으로 줄이고 $5.99~6.99 — The Exit 8 포지션. 완성도에 집중
- **B.** 2~3시간을 유지하되 **N7 무작위화를 Could가 아니라 Must로 올린다** — 반복 가치가 분량을 지탱해야 함

현재 문서는 무작위화가 `Could`(여유 있으면)에 있습니다. **B를 택한다면 이건 모순입니다.**

## 🟠 4-3. 로드맵이 자기 규칙을 안 지킨다

`06-roadmap.md` §5-1: *"추정 시간은 3배로 잡는다."*
그런데 로드맵 자체는 3배가 반영돼 있지 않습니다. 게다가 **M0에 Godot 4 학습이 포함**돼 있는데
이건 그 자체로 큰 항목입니다.

현실적으로 2027년 4~5월 출시는 **하반기로 밀릴 가능성이 높습니다.**
문제는 밀리는 것 자체가 아니라, 밀렸을 때 **Next Fest → 출시 간격이 무너지는 것**입니다.

→ M5(본편)에 **버퍼 1개월을 미리 넣어두세요.** 컷 라인은 있지만 버퍼가 없습니다.

## 🟡 4-4. 거짓 수칙 첫 조우에서 죽이지 마라

H1(거짓 수칙이 짜증이 아니라 재미인가)은 정확히 짚은 가설입니다. 여기에 설계 하나를 더합니다.

**첫 번째 거짓 수칙과 마주쳤을 때는 죽이지 않는 걸 권합니다.**

플레이어는 아직 "이 게임의 수칙은 거짓말을 할 수 있다"는 문법을 모릅니다.
그 상태에서 죽으면 **학습이 아니라 배신으로 인식**됩니다. H1이 실패하는 가장 흔한 경로입니다.

첫 거짓 수칙은 **경고 또는 근접 실패**로 처리하고, 3초 리플레이로 "이 수칙은 필체가 달랐다"를
보여주세요. 문법을 학습한 다음부터 긴장이 시작됩니다.

## 🟡 4-5. H3(한국 배경이 이국적 매력인가)의 비대칭성

문서는 H3을 *"틀리면 배경 추상화"* 로 대응하겠다고 했습니다. 합리적입니다.

여기에 이 저장소의 관찰을 덧붙입니다 — PEAK(산), R.E.P.O.(폐건물), MECCHA CHAMELEON(색칠)
**최근 히트작은 전부 문화 코드가 0입니다.**

다만 NIGHTSHIFT는 김장과 결정적으로 다릅니다:

| | 김장 | NIGHTSHIFT |
|---|---|---|
| 문화 요소의 역할 | **게임의 목적** — 김장을 하는 게 게임 | **배경** — 편의점은 무대일 뿐 |
| 자랑하는가 | 사실상 그렇게 읽힘 | 아니다. 오히려 심야 노동의 피로를 그린다 |

김치워리어와 국방부 게임이 욕먹은 이유는 **문화를 자랑하려 했기** 때문이지 문화를 썼기 때문이 아닙니다.
NIGHTSHIFT는 편의점을 자랑하지 않습니다. 안전합니다.

> 다만 스토어 페이지 태그·설명에서 "한국"을 전면에 세우지는 마세요. **호러와 규칙을 앞에 두고,
> 한국적 질감은 플레이하면서 발견하게 두는 편**이 H3 리스크를 줄입니다.
