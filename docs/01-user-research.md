# 01. 사용자 조사

> ⚠ **정직성 고지**: 이 문서는 **실제 플레이어 인터뷰 결과가 아니다.**
> 현재까지 조사한 사용자는 0명이다. 이 문서는 (A) 시장 리서치에서 나온 2차 자료, (B) 그로부터 도출한 **검증되지 않은 가설**, (C) 실제 조사를 실행하기 위한 계획으로 구성된다.
> 가설을 사실처럼 취급하는 순간 이 프로젝트는 방향을 잃는다.

---

## A. 2차 자료 (리서치 기반 근거)

### A-1. 시장이 말해주는 것

| 근거 | 함의 |
|---|---|
| 2025년 Steam 신작 median 매출 약 $249, 신작 절반이 리뷰 10개 미만 | 만들면 팔린다는 가정은 틀렸다. 발견성이 전부다. |
| 호러 장르 히트율 3.2%로 상승세, 2D 플랫포머 0.18% | 장르 선택만으로 성공 확률이 17배 차이난다. |
| 2025 상반기 Steam 신작 판매량 상위권을 소셜/코옵 호러가 점유 | 스트리머 노출이 인디 발견성의 최대 지렛대. |
| The Exit 8, Buckshot Roulette 등 1~2시간 저가 호러의 연속 성공 | 짧고 밀도 높은 게임에 돈을 낸다. |

### A-2. 이 장르 플레이어에 대해 관찰 가능한 사실

- **스트리머와 시청자가 같이 푼다.** 규칙 추론 게임은 채팅이 정답을 외치는 구조라 방송 적합도가 높다. → 실패 순간이 재밌어야 한다.
- **짧은 세션을 선호한다.** 한 판이 10분 내외여야 "한 판만 더"가 성립한다.
- **스포일러에 민감하다.** 규칙 기반 게임은 정답이 유출되면 가치가 급락한다. → 절차적 변주 또는 다회차 변화가 필요하다.

## C. 조사 실행 계획

### C-1. 지금 당장 (비용 0, 1주)

**데스크 리서치 — 남의 리뷰를 읽는다**
- [ ] Papers, Please / The Exit 8 / Chilla's Art 게임들의 Steam **부정 리뷰** 각 50개 정독
  - 목적: 이 장르에서 사람들이 **무엇에 화를 내는지** 파악. 긍정 리뷰보다 정보량이 많다.
  - 산출: `docs/research/negative-review-themes.md`에 반복되는 불만 5개 정리
- [ ] r/horrorgaming, r/indiegames, 루리웹·인벤 인디 게시판에서 "규칙 호러" 관련 스레드 반응 수집
- [ ] 위 게임들의 유튜브 실황 3편씩 시청, **시청자 채팅 반응**이 터지는 지점 타임스탬프 기록
  - 목적: 스트리머 친화 설계의 실제 근거 확보

### C-2. 프로토타입 이후 (M2~M3)

**게릴라 플레이테스트 — 5명이면 충분하다**
- 대상: 호러 게임을 즐기는 지인 3명 + 전혀 모르는 사람 2명
- 방식: 화면 공유로 15분 플레이, **절대 설명하지 않는다**. 막히는 지점이 곧 UX 결함이다.
- 반드시 측정할 것:
  - [ ] 첫 30초 안에 "무엇을 해야 하는지" 스스로 알아냈는가 (부스 시연 생존 조건)
  - [ ] 첫 실패 후 다시 하고 싶어했는가
  - [ ] "거짓 수칙"을 처음 만났을 때 반응이 웃음/감탄인가, 짜증인가 (**H1 검증**)
  - [ ] 이동하고 싶다고 말했는가 (**H2 검증**)
- 기록: `docs/research/playtest-YYYYMMDD.md`

### C-3. 데모 공개 이후 (M5~M6)

- [ ] Steam 데모 지역별 위시리스트 분포 확인 → **H3 검증**
- [ ] 게임 내 익명 텔레메트리: 밤별 이탈 지점, 평균 세션 길이, 실패 원인 분포
  - 개인정보 수집 금지. 집계 수치만. Steam 개인정보 정책 준수.
- [ ] 데모 플레이어 대상 3문항 설문 (더 길면 아무도 안 한다)
  1. 가장 기억에 남는 순간은?
  2. 가장 답답했던 순간은?
  3. 정식판이 나오면 얼마면 사겠는가?

## D. 조사 규율

1. **가설과 사실을 문서에서 시각적으로 구분한다.** 이 문서는 A/B/C 섹션으로 분리되어 있다. 이 구조를 깨지 마라.
2. **5명이면 충분하다.** 완벽한 표본을 기다리다 아무 조사도 안 하는 게 최악이다.
3. **내가 듣고 싶은 말을 묻지 않는다.** "재밌었어?"가 아니라 "어디서 막혔어?"를 묻는다.
4. **테스터가 하는 말이 아니라 하는 행동을 본다.** 말은 예의를 차리지만 손은 정직하다.
5. 검증된 가설은 이 문서에서 **B → A로 승격**시키고 날짜를 남긴다.
