# 개발 로드맵 & 리스크

## 0. 전제

- 남은 기간: **약 3.5개월** (2026년 8월 초 → 11월 중순 지스타)
- 가정 팀 규모: **2~4명** (프로그래머 1~2, 아트/TA 1, 기획·사운드 겸업 1)
- 엔진: **Unity 6 LTS** 권장 — 파티클/셰이더 툴링이 성숙하고 국내 인력 풀이 넓습니다.
  Godot 4도 이 스코프엔 충분히 적합합니다. 언리얼은 이 아트 방향에 오버킬입니다.

> 팀 규모가 1인이라면 스코프를 절반으로 줄이세요: 무기 1종, 적 3종, 보스 없음.
> 그래도 부스 빌드로는 충분히 성립합니다.

## 1. 마일스톤

### M1 — 프로토타입 (2주) 🚦 **게이트**

**목표: 재미가 있는지 없는지 판정.**

- 이동 + 발도 + 잡졸 1종
- 적 플로킹(뭉치기) AI — **여기에 M1의 절반을 씁니다**
- 점수 = 처치수² 만 구현
- 회색 박스 그래픽. 이펙트 없음

> **게이트 판정**: 이펙트가 하나도 없는 회색 박스 상태에서 팀원이 "한 판 더" 하고 싶어야 합니다.
> 그렇지 않다면 이펙트로는 절대 못 살립니다. 여기서 피벗하세요. (ALT_CONCEPTS.md 참고)

### M2 — 게임필 (3주)

**목표: "한 방의 쾌감" 완성. 이 3주가 게임의 품질을 결정합니다.**

- 히트스톱, 카메라 워크, 슬로우모션
- 참격 궤적, 파편 분리, 파티클
- 처치 수 단계별 연출 4단계 (CONCEPT.md §5)
- 사운드 + **정적** 연출

### M3 — 콘텐츠 (3주)

- 적 4종 (잡졸/돌격병/방패병/폭발체)
- 무기 2종 (카타나: 전방 부채꼴 / 대태도: 전방향 원형·느림)
- 보스 1마리
- 3분 세션 난이도 곡선 밸런싱

### M4 — 부스 빌드 (2주)

- 어트랙트 모드, 로컬 랭킹, 이름 입력, 자동 리셋
- 워치독, 크래시 방지, 컨트롤러 핫플러그, 키 차단
- **3분 세션 200회 자동 반복 테스트**

### M5 — 외부 플레이테스트 & 폴리싱 (2주)

- 모르는 사람 대상 테스트 **2회 이상** (GSTAR_BOOTH.md §5의 3개 지표 측정)
- 피드백 반영. 콘텐츠 추가 금지, 오직 수정만

### M6 — 버퍼 (1주)

- 예비 기간. **반드시 비워두세요.** 여기까지 쓰게 됩니다
- 트레일러 15초 컷 + 스팀 페이지 오픈 (부스 전에 열려 있어야 QR이 의미가 있습니다)

## 2. 스코프 동결선

**M3 종료 시점에 콘텐츠를 동결합니다.** 이후 추가 금지.

지스타 빌드 최종 스펙:
- 스테이지 **1개**
- 적 **4종**
- 무기 **2종**
- 보스 **1마리**

이것보다 늘리려는 유혹이 반드시 옵니다. 늘리지 마세요.
부스 방문자는 3분만 플레이합니다. 3분 안에 보이지 않는 콘텐츠는 **존재하지 않는 것과 같습니다.**
그 시간을 게임필에 쓰는 편이 위시리스트를 10배 더 모읍니다.

## 3. 스팀 확장 로드맵 (지스타 이후)

지스타 빌드는 스팀 데모의 **부분집합**이 되도록 설계합니다. 버리는 작업이 없어야 합니다.

### 런 구조 (로그라이트)

```
스테이지 1 → 유물 3택1 → 스테이지 2 → 유물 → 스테이지 3 → 보스
```
1회 런 20~30분.

### 무기 = 발도 패턴 변경

무기가 곧 게임 규칙입니다. 이게 리플레이성의 핵심입니다.

| 무기 | 패턴 | 플레이 변화 |
|---|---|---|
| 카타나 | 전방 부채꼴 | 기본. 방향을 맞춰야 함 |
| 쌍검 | 좁은 범위 2연속 | 정밀. 콤보 유지형 |
| 대태도 | 전방향 원형, 쿨 김 | 완전히 뭉쳐야만 이득 |
| 창 | 직선 관통, 초장거리 | 일렬로 세우는 유인이 필요 |
| 사슬낫 | 적을 끌어당긴 뒤 벰 | **능동적 뭉치기.** 가장 높은 스킬 실링 |

### 그 외

- 보스: 벨 수 없는 적 → 부위를 베어 무장해제 → 본체 일섬
- 데일리 챌린지 + 글로벌 리더보드
- 리플레이 클립 자동 저장 및 공유 (스트리머·숏폼 유입 경로)
- 가격 **$12~15**, 플레이타임 8~15시간
