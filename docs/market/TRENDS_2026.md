# 2026 시장 조사 — 지금 뭐가 팔리고 있나

조사일: 2026년 8월. 출처는 문서 하단.

## 1. 숫자부터

| 사실 | 수치 |
|---|---|
| 인디 게임의 스팀 전체 매출 점유율 | **48%** (2018년 24% → 2배) |
| 코옵 장르 매출 (2025 상반기) | **$41억** — 장르 역대 최고 6개월 기록 |
| R.E.P.O. 판매량 | **1,600만 장** |
| PEAK 판매량 | **1,000만 장 이상** (개발비 **$200,000 미만**, 개발 기간 수 주) |
| PEAK 가격 | **$7.99** |
| 스팀 신작 출시 | **하루 70~80개**, 월 $1,000 이상 버는 게임은 **5% 미만** |
| 인디 중앙값 수익 | 평생 $5,000~15,000 |
| 리뷰 100개 + "매우 긍정적" 달성 시 | $75,000~300,000+ |

마지막 두 줄이 핵심입니다. **중앙값은 처참하고, 상위는 폭발합니다.** 중간이 없습니다.
"괜찮은 게임"을 만들면 $5,000을 법니다. 목표는 괜찮은 게임이 아니라 **화제가 되는 게임**이어야 합니다.

## 2. 지배적 트렌드 — "프렌드슬롭(friendslop)"

원래는 "친구끼리 하는 싸구려 멀티게임"이라는 **비하 표현**이었습니다. 지금은 스팀 최대 장르입니다.
PEAK 개발사는 아예 이렇게 말했습니다 — *"We proudly wear the friendslop badge."*

### 공통 공식

| 요소 | 내용 |
|---|---|
| 인원 | **3~4인 PvE 코옵** |
| 조작 | 이동 + 잡기. 사실상 그게 전부 |
| 핵심 | **물리 기반 카오스** — 실패가 자동으로 웃김 |
| 소통 | **근접 음성 채팅** — 위치에 따라 목소리가 들리고 안 들림 |
| 가격 | **$8~20** |
| 목표 | 재미가 아니라 **클립**. 숏폼에 올라갈 30초 |

### 대표작 해부

| 게임 | 익숙한 동사 | 신박한 비틀기 |
|---|---|---|
| **PEAK** | 오르다 | 4인이 로프로 묶여 있고, 스태미나가 있고, 지형이 매번 다르다 |
| **R.E.P.O.** | 옮기다 | 물건이 **진짜로 깨진다**. 조심해야 하는데 조작이 부정확하다 |
| **MECCHA CHAMELEON** | 숨다 | **몸에 직접 물감을 칠해서** 배경에 섞인다 |
| **We Are So Cooked** | 치우다 | 시체를 넷이서 팔다리 하나씩 잡고 옮긴다. 방향이 안 맞으면 계단에서 굴린다 |
| **Windrose** | 살아남다 | 해적 코옵. 넥스트페스트 위시리스트 1위 (35만), 이후 100만 돌파 |

## 3. 「신박한데 익숙한」의 정체

이 트렌드에서 뽑아낸 공식입니다. 예외가 거의 없습니다.

```
누구나 아는 동사 하나
        +
그 동사를 마음대로 못 하게 만드는 물리
        +
실패가 팀 전체에 전파되는 구조
        +
3~4인 & 근접 음성
```

### 왜 이게 통하는가

1. **설명이 필요 없다.** "산 오르는 게임"이면 끝. 트레일러 3초면 이해합니다
2. **실패가 콘텐츠다.** 물리는 개발자가 안 만든 상황을 무한히 생성합니다. 콘텐츠 제작비가 사실상 0
3. **바이럴 계수가 곧 판매 계수다.** 4인 코옵은 1명이 사면 3명이 더 삽니다. 마케팅비가 게임 구조에 내장됨
4. **관전이 재밌다.** 스트리머·숏폼 유입 경로가 자동으로 열립니다
5. **저예산으로 가능하다.** PEAK이 $200,000 미만으로 1,000만 장을 팔았습니다

> **가장 중요한 한 줄**:
> R.E.P.O.와 PEAK의 진짜 발명은 *"극도로 조심해야 하는 상황을 주고, 조심할 수 없는 조작을 준다"* 입니다.
> 이 긴장이 코미디를 만들고, 코미디가 클립을 만들고, 클립이 판매를 만듭니다.

## 4. 포화 문제 — 그리고 답

프렌드슬롭은 **이미 포화**입니다. 다들 뛰어들었습니다.

그런데 MECCHA CHAMELEON은 2026년에 출시 첫 주 100만 장을 팔았고, 하데스 2의 스팀 동시접속 최고치를 넘겼습니다.
같은 시각 프렌드슬롭 장르 전체 동시접속은 35만 명이었습니다. 시장은 죽지 않았습니다.

**통과 조건은 하나입니다: 공식을 따르되, 메커닉 하나는 아무도 안 해본 것이어야 합니다.**
숨바꼭질은 널렸지만, *물감으로 직접 몸을 칠하는* 숨바꼭질은 없었습니다. 그 하나로 뚫었습니다.

## 5. 한국 개발사의 추가 카드 — 문화적 후킹

조사 중 확인된 실제 흐름입니다. 한국 스튜디오들이 **K-소재를 글로벌 후킹 포인트로** 쓰고 있습니다.

이미 스팀에 있는 것들:
- **Kimbap Heaven Simulator** (김밥천국 시뮬)
- **POJANGMACHA** (포장마차 경영 시뮬)
- **Korean BBQ Simulator**

**중요한 관찰**: 이것들은 **전부 혼자 하는 힐링/경영 시뮬**입니다.
**K-소재 × 4인 물리 카오스 코옵은 아직 아무도 안 했습니다.**

수요는 이미 증명됐고(위 게임들이 팔리고 있음), 가장 뜨거운 형식과의 교집합은 비어 있습니다.

## 6. 아트 — 저예산이 불리하지 않다

- 강한 스타일라이즈드가 저예산 리얼리즘을 **항상** 이깁니다. 스타일은 예산과 무관합니다
- 2026년에 통하는 원칙: **제한된 팔레트 / 읽히는 실루엣 / 일관된 시각 규칙 / 포스트프로세싱을 정체성으로 / 제약을 기능으로**
- 소규모 팀이 AAA 리얼리즘을 노리는 건 프로젝트 실패 공식입니다

## 7. 결론 — 첫 기획 「일섬」을 보류하는 이유

「일섬」은 **싱글플레이 스코어어택 액션**이었습니다. 2026년 기준으로:

- 바이럴 계수 = 1 (친구를 데려오지 않음)
- 클립성은 있으나 "친구가 웃기게 실패하는" 종류가 아님
- 액션 게임은 폴리싱 경쟁이 극심하고, 폴리싱은 예산 싸움
- 부스에서 **1명만** 플레이 → 회전율과 소음(환호) 모두 불리
- 무엇보다 **신박함이 없음**. 익숙한 것들의 안전한 조합이었음
