# 대안 컨셉

메인 컨셉(「일섬」)이 M1 게이트를 통과하지 못했을 때의 피벗 후보입니다.
둘 다 "조작 극단적 단순 + 관전 임팩트 + 3분 세션"이라는 동일한 제약에서 설계했습니다.

---

## 대안 A — 「합 (合)」 2인 협동 거대 보스전

### 개요

거대 보스 **1마리**를 두 명이 3분 안에 격파하는 협동 보스러시.

```
스틱   →  이동
버튼 A →  공격
버튼 B →  회피
```

### 코어

- 보스의 각 부위(팔, 다리, 머리)에 파괴 게이지가 있음
- 두 사람이 **같은 부위를 동시에** 치면 「합격기」 — 데미지 5배 + 화면 가득 폭발
- 즉 게임의 전부가 **"타이밍을 맞추자"** 는 소통입니다. 서로 소리를 지르게 됩니다

### 장점

- **부스 소셜성 최강.** 친구·커플·부모자식이 함께 → 대기줄 회전율이 사실상 2배
- 거대 보스는 화면을 가득 채웁니다 → **부스에서 시선 강탈 1위**. 멀리서도 무조건 보입니다
- 두 사람이 서로 소리치는 광경 자체가 부스의 홍보물이 됩니다
- 클립성이 가장 높음 (둘이 환호하는 장면)

### 단점 / 위험

- **아트 부담이 큽니다.** 거대 보스는 실루엣으로 때울 수 없습니다. 애니메이션·리깅 필수
- 3.5개월에 보스 여러 마리는 불가능 → 부스 빌드는 **1마리**로 고정해야 함
- 혼자 온 방문객 대응 필요 (스태프가 파트너로 들어가거나 AI 파트너 모드)
- 스팀 버전은 온라인 코옵이 필요해짐 → 넷코드 비용

> 아트 인력이 확보되어 있다면 이 안이 부스 성적은 더 좋을 가능성이 높습니다.
> 프로그래머 중심 팀이면 「일섬」이 안전합니다.

---

## 대안 B — 「투척 (投)」 던지기 하나로 모든 것을

### 개요

모든 행동이 **던지기 하나**로 통합된 액션 플랫포머.

```
스틱   →  이동
버튼 1 →  던지기 / 회수
```

### 코어

던진 칼이 세 가지 역할을 동시에 합니다:

1. **무기** — 맞은 적을 죽인다
2. **이동** — 던진 칼 위치로 순간이동한다
3. **지형** — 벽에 박힌 칼을 발판으로 밟는다

버튼 하나로 공격·이동·플랫포밍이 전부 해결됩니다. 조작 학습 시간이 사실상 0입니다.

### 장점

- 스킬 표현의 폭이 매우 넓음 → 고수 영상이 압도적으로 멋있음
- 실력 곡선이 길고 자연스러움 → 스팀 리플레이성 우수
- 저비용 아트와 궁합이 좋음

### 단점 / 위험

- **레벨 디자인 부담이 큽니다.** 이 장르는 스테이지 품질이 전부인데, 좋은 레벨은 시간이 오래 걸립니다
- "적을 모아서 한 방"처럼 **관전자가 한눈에 알아보는 임팩트 순간**이 약합니다
- 부스에서 처음 잡은 사람이 벽에 부딪히며 헤맬 위험 → 3분이 좌절로 끝날 수 있음

> 스팀 게임으로서는 가장 매력적일 수 있으나, **부스 게임으로서는 세 안 중 가장 약합니다.**
> 지스타를 주 목표로 한다면 우선순위를 낮추세요.

## 세 안 비교

| 기준 | 일섬 (메인) | 합 (협동 보스) | 투척 |
|---|:---:|:---:|:---:|
| 조작 학습 속도 | ◎ | ○ | ◎ |
| 부스 관전 임팩트 | ◎ | ◎◎ | △ |
| 3.5개월 실현성 | ◎ | △ | ○ |
| 아트 인력 요구 | 낮음 | **높음** | 낮음 |
| 스팀 리플레이성 | ○ | ○ | ◎ |
| 부스 회전율 | ○ | ◎ | △ |

**결론**: 프로그래머 중심 소규모 팀 + 3.5개월이면 **「일섬」**.
전담 아티스트가 있다면 **「합」**을 재검토할 가치가 있습니다.

## 참고 — 과거 시도 기록

**VR 야구 심판 게임** (볼/스트라이크 판정) — 반응이 저조했던 프로젝트.

한 줄만 기록해둡니다. 이번 컨셉의 설계 근거가 되기 때문입니다.

> **판정하는 게임은 플레이어가 상황을 만들 수 없다.**
> 공은 저절로 날아오고 플레이어는 반응만 합니다. 잘해도 화면에 변화가 없고,
> 뒤에서 보는 사람 입장에서는 아무 일도 일어나지 않습니다.

그래서 이번 세 안은 모두 **플레이어가 능동적으로 상황을 만들어내는 구조**로 잡았습니다 —
적을 모으고(일섬), 타이밍을 맞추고(합), 발판을 만듭니다(투척).
그리고 그 결과가 **화면에서 즉시 커집니다.** 부스 게임에서 이건 선택이 아니라 필수 조건입니다.
