# 머릿속 플레이테스트 — 3안을 실제로 돌려봤다

만들었다고 가정하고 0초부터 시뮬레이션한 기록입니다. **세 안 모두 깨졌습니다.**
깨진 지점이 중요합니다. 거기서 설계 법칙이 나왔고, 그 법칙으로 다시 만들었습니다.

# 시뮬레이션 1 — 김장 (초안)

### 00:00 — 시작

4명이 마당에 떨어진다. 배추 더미, 대야, 할머니.

**즉시 깨짐.** 아무도 뭘 해야 할지 모른다.

김장 공정은 6단계다. **한국인도 순서를 모른다.** 외국인은 더 모른다.
오버쿡드가 되는 이유는 **주문서가 항상 화면에 떠 있기** 때문이다. 김장에는 그게 없다.

> 🔴 **결함 1: 목표가 화면에 없다.**

### 01:00 — 양념 바르기

"배춧잎 사이사이에 양념을 바른다"를 어떻게 조작하나?

마우스로 문지르나? 그러면 조작이 하나 늘어난다. **"이동 + 잡기"가 무너진다.**
R.E.P.O.도 PEAK도 조작은 잡기 하나뿐이다. 정밀 작업을 요구하는 순간 이 장르가 아니게 된다.

> 🔴 **결함 2: 정밀 조작을 요구한다.**

### 02:00 — 그런데 이게 재밌나?

배추 옮기고, 담그고, 바르고, 통에 넣고. 솔직히 이건 **작업**이다.

배추를 떨어뜨려도 그냥 주우면 된다. **잃는 게 없다.** 긴장이 없다.

여기서 성공작들을 다시 봤다:

| 게임 | 되돌릴 수 없는 손실 |
|---|---|
| PEAK | 추락 — 올라간 높이를 잃는다 |
| R.E.P.O. | 파손 — 물건이 깨지면 끝이다 |
| We Are So Cooked | 발각 |
| MECCHA CHAMELEON | 발각 |

**전부 되돌릴 수 없다.** 김장은 전부 되돌릴 수 있다.

> 🔴 **결함 3: 되돌릴 수 없는 손실이 없다. → 긴장이 0이다.**

**판정: 컨셉은 매력적인데 게임 구조가 없다.**

# 시뮬레이션 2 — 거신

### 00:00

4명이 조종석. P1 왼다리, P2 오른다리, P3 왼팔, P4 오른팔.

### 00:10 — 넘어진다

왼다리가 다리를 들었는데 오른다리가 안 버텼다. 당연하다. 처음이니까.

### 00:40 — 아직 못 일어난다

넷이 팔다리를 허우적댄다. 일어나려면 4명이 정확한 순서로 움직여야 한다.

### 01:30 — **아직도 못 일어난다**

여기서 문제가 명확해진다.

**QWOP이 왜 1인 게임인가?** 조율 비용 때문이다. 혼자서도 어려운 걸 넷이 나누면 난이도가 4배가 아니라 **조합 폭발**한다.

비교해보면 답이 나온다:

- **Human Fall Flat** — 각자 **완전한 몸 하나**를 조종한다. 분산 조종이 아니다
- **Lovers in a Dangerous Spacetime** — 각 스테이션이 **독립적으로 유용**하다. 포탑은 혼자 쏴도 적이 죽는다

거신은 **모든 행동이 4인 동시 조율을 요구한다.** 이건 재미가 아니라 마비다.
부스에서 첫 3분이 순수한 좌절이면 컨트롤러를 놓는다.

> 🔴 **결함 4: 혼자서 할 수 있는 유용한 행동이 하나도 없다.**

**판정: 4인에서 붕괴. 2인(왼쪽 몸 / 오른쪽 몸)이면 성립 가능.**

# 시뮬레이션에서 나온 5법칙

세 번의 붕괴에서 나온 것들입니다. 이 장르의 게임은 5개를 **전부** 만족해야 합니다.

| # | 법칙 | 깨진 안 |
|---|---|---|
| 1 | **목표가 항상 화면에 보여야 한다** | 김장 |
| 2 | **되돌릴 수 없는 손실이 있어야 한다** | 김장 |
| 3 | **혼자서도 유용한 일을 할 수 있어야 한다** | 거신 |
| 4 | **실패해도 진행의 일부는 남아야 한다** | 탑 |
| 5 | **조작은 "잡기" 하나로 전부 표현돼야 한다** | 김장 |

## 검증 — PEAK은 5개를 다 통과한다

| 법칙 | PEAK |
|---|---|
| 1. 목표 가시성 | **위.** 항상 보인다 |
| 2. 되돌릴 수 없는 손실 | 추락 · 스태미나 · 소모 아이템 |
| 3. 독립 행동 | 혼자서도 오를 수 있다 |
| 4. 진행 보존 | 캠프파이어 체크포인트 |
| 5. 조작 | 이동 + 잡기 |

R.E.P.O.도, MECCHA CHAMELEON도 마찬가지로 5개를 다 통과합니다.
**이건 우연이 아니라 이 장르의 구조 조건입니다.**

# 재설계 — 김장을 5법칙으로 고치다

김장은 컨셉이 아까웠습니다. 버리지 않고 5법칙에 맞춰 다시 만들었습니다.
**고치고 나니 완전히 다른 게임이 됐습니다.**

## 열쇠 하나: 양념을 유한 자원으로 만든다

```
양념은 한 통뿐이다. 흘리면 사라진다. 그리고 물리라서 반드시 흘린다.
```

이 한 줄이 결함 1, 2, 3을 동시에 해결합니다.

| 법칙 | 해결 |
|---|---|
| 1. 목표 가시성 | 화면에 게이지 **딱 2개** — `양념 잔량` ↓ / `김치통 채움` ↑ |
| 2. 되돌릴 수 없는 손실 | **흘린 양념은 영원히 사라진다.** 이게 긴장이다 |
| 5. 정밀 조작 | 바르지 않는다. **양념통에 넣고 흔든다.** 조작은 여전히 잡기 하나 |

그리고 이건 R.E.P.O.의 구조와 정확히 같습니다 — **조심해야 하는데 조심할 수 없다.**

## 열쇠 둘: 흘린 양념이 지형이 된다

```
바닥에 흘린 양념 = 미끄러운 바닥
```

이게 이 설계에서 가장 마음에 드는 부분입니다.

- 실수 → 양념 흘림 → 바닥이 미끄러워짐 → 넘어짐 → **더 흘림** → 악순환
- **실패의 결과가 누적되어 난이도가 저절로 올라갑니다.** 난이도 곡선을 손으로 안 짜도 됩니다
- 그리고 이전 안에서 "화면이 빨개진다"고 했던 시각 아이디어가 이제 **게임 메커닉 그 자체**가 됩니다.
  빨간 정도 = 잃은 자원 = 바닥의 위험도. 보기만 해도 상태를 알 수 있습니다

> 걸레로 닦으면 회복됩니다. → **아무도 하기 싫어하는 역할**이 생깁니다. → `"야 좀 닦아!!"` → 코미디.

## 5법칙 재검증

| 법칙 | 수정된 김장 |
|---|---|
| 1. 목표 가시성 | 게이지 2개. 양념 vs 김치통. 끝 |
| 2. 되돌릴 수 없는 손실 | 흘린 양념은 안 돌아온다 |
| 3. 독립 행동 | 씻기·나르기·닦기는 전부 혼자 가능. 김치통 운반만 2인 |
| 4. 진행 보존 | 이미 담근 김치는 절대 사라지지 않는다 |
| 5. 조작 | 이동 + 잡기 + (잡은 채로) 흔들기. **버튼 추가 없음** |

**전부 통과.** 상세 설계는 [KIMJANG.md](KIMJANG.md)에 있습니다.

# 다른 두 안의 처방

기각이 아니라 **수리 가능**합니다. 다만 김장보다 손이 더 갑니다.

## 거신 → **2인으로 축소**

왼쪽 몸 / 오른쪽 몸. 조율 비용이 조합 폭발에서 단순 협응으로 내려옵니다.
그리고 팔은 독립적으로 유용하게 만듭니다 — 한 손으로도 물건을 집을 수 있어야 합니다(법칙 3).
넘어졌을 때 일어나는 건 **자동 재시도 보조**를 넣습니다(법칙 4).

## 탑 → **아래층 석화**

물이 닿은 아래층은 **굳어서 영구 지형이 됩니다.** 무너져도 굳은 높이까지는 보존됩니다.
PEAK의 체크포인트와 같은 역할입니다. 이걸 넣으면 법칙 4를 통과합니다.

# 결론

시뮬레이션 전과 후의 김장은 다른 게임입니다.

| | 시뮬레이션 전 | 시뮬레이션 후 |
|---|---|---|
| 목표 | 김장을 한다 (모호) | 양념 떨어지기 전에 김치통을 채운다 |
| 긴장 | 없음 | 유한 자원이 계속 새어나간다 |
| 난이도 곡선 | 손으로 짜야 함 | **실패가 바닥을 미끄럽게 만들어 자동 상승** |
| 조작 | 바르기(정밀) | 흔들기(잡기의 연장) |
| 시각 | 예뻐 보이는 것 | **화면의 빨간 정도 = 남은 자원 = 위험도** |

컨셉이 좋은 것과 게임이 되는 것은 다른 문제였습니다. 머릿속에서 돌려보지 않았으면 몰랐을 겁니다.
