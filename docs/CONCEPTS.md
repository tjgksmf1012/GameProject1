[TRENDS_2026.md](TRENDS_2026.md)에서 도출한 공식을 적용한 안들입니다.

```
누구나 아는 동사  +  그걸 마음대로 못 하게 만드는 물리
                 +  실패가 팀 전체에 전파되는 구조

```

세 안 모두 조작은 **이동 + 잡기** 뿐입니다. 그 이상 넣지 않습니다.

# 1안 ⭐ 「김장 KIMJANG」

> **넷이서 김장을 한다. 배추는 미끄럽고, 양념은 튀고, 할머니가 보고 있다.**

## 왜 이게 1순위인가

시장에 **비어 있는 교집합**이 정확히 하나 보입니다.

- K-소재 게임은 이미 통하고 있습니다 — 김밥천국 시뮬, 포장마차, 한국 BBQ 시뮬이 스팀에 나와 있습니다
- 그런데 **그것들은 전부 혼자 하는 힐링 시뮬**입니다
- **K-소재 × 4인 물리 카오스 코옵은 아무도 안 했습니다**

수요는 증명됐고, 가장 뜨거운 형식과의 교집합은 비어 있습니다. 이런 자리는 자주 나오지 않습니다.

## 익숙한 것 / 신박한 것

| | |
|---|---|
| **익숙** | 요리 협동 게임. 3초면 이해합니다 |
| **신박** | 요리가 아니라 **대량 노동**입니다. 그리고 **전부 물리**입니다 — 배추가 미끄러지고, 양념이 튀고, 김치통은 혼자 못 듭니다 |

> **오버쿡드와 다른 점**: 오버쿡드는 *주문 처리*(리듬 게임)이고 아이템은 손에 딱 붙습니다.
> 김장은 *물량 처리*(축적 게임)이고 **모든 것이 물리로 흘러내립니다.** 완전히 다른 장르입니다.

## 공정 = 자동으로 생기는 분업 라인

```
① 절이기 → ② 씻기 → ③ 양념 만들기 → ④ 버무리기 → ⑤ 통에 담기 → ⑥ 김치냉장고로 운반
```

넷이 라인을 짜야 합니다. 누가 시키지 않아도 자연스럽게 역할이 갈립니다.
그리고 **한 명이 막히면 라인 전체가 정체됩니다.** 이게 실패 전파 구조입니다.

## 실패가 웃긴 이유

| 상황 | 결과 |
|---|---|
| 배추가 미끄럽다 | 떨어뜨림 → 흙 묻음 → **씻기 공정으로 되돌아감** → 뒤가 다 밀림 |
| 양념은 액체다 | 튄다 → 서로에게 묻는다 → 캐릭터가 점점 빨개진다 |
| 김치통은 무겁다 | 혼자 못 든다 → 사람을 부르러 가야 한다 → "야 이리 와봐!!" |
| 마당이 좁다 | 부딪힌다 → 들고 있던 걸 놓친다 → 연쇄 |
| 할머니 NPC가 감독한다 | 잘못하면 등짝. 잘하면 수육 |

## 시각 — 이게 이 기획의 진짜 무기

```
게임 시작:  흰 배추 · 깨끗한 마당 · 하얀 앞치마
게임 종료:  온 화면이 빨강 · 캐릭터도 빨강 · 바닥도 빨강
```

**진행도가 곧 화면 색입니다.** 5m 밖에서 봐도 저 팀이 지금 어떤 상태인지 압니다.

이게 왜 중요하냐면 — **유튜브 썸네일과 스팀 스크린샷이 저절로 만들어집니다.**
빨간 난장판 속에서 네 명이 허우적대는 그림은 설명이 필요 없습니다. 클릭률이 예산과 무관해집니다.

## 문화 후킹의 양방향성

- **외국인**: "저 거대한 빨간 걸 왜 저렇게 많이 만들지?" → 궁금증 자체가 마케팅입니다
- **한국인**: 즉시 이해 + 향수. "우리 엄마가 저러셨는데"
- **지스타**: 한국 개발사가 김장 게임을 내놓는 것 자체가 기사 소재입니다

## 확장 축

- **장소**: 아파트 베란다(너무 좁음) → 시골 마당(넓지만 우물이 멂) → 옥상(바람) → 산속 절(물을 길어와야 함)
- **계절**: 겨울 배추김치 → 봄 열무 → 여름 오이소박이 (콘텐츠 업데이트 축이 이미 있음)
- **엔딩**: 완성한 김치를 할머니가 먹어보고 평가

## 스펙

가격 **$9.99~12.99** / 1~4인 온라인 코옵 + 근접 음성 / 스타일라이즈드 3D, 로우폴리

## 리스크

- 오버쿡드 아류로 보일 위험 → **트레일러 첫 5초에 물리로 미끄러지는 배추**를 보여줘서 즉시 구분시켜야 합니다
- 문화 소재가 장벽이 될 가능성 → 데이터상으로는 오히려 후킹으로 작동 중입니다

# 2안 「거신 巨神」

> **거인 하나를 넷이서 부위별로 나눠 조종한다. 걷는 것부터가 협동 과제다.**

## 익숙한 것 / 신박한 것

| | |
|---|---|
| **익숙** | 거대 로봇/거인. 설명 0초 |
| **신박** | 각자 **한 부위만** 조작합니다. 그리고 거인은 **진짜 물리로 넘어집니다** |

```
P1 왼다리 · P2 오른다리 · P3 왼팔 · P4 오른팔
```

걷기 = 다리 담당 둘이 번갈아 내밀어야 합니다. 박자가 어긋나면 넘어집니다.
넘어지면 **일어나는 것도 넷이 협동**해야 합니다. 여기가 이 게임의 하이라이트입니다.

> `"왼발! 왼발!!"` `"어느 쪽 왼발?!"` — 이 대사가 게임 시스템에서 자동으로 나옵니다.

## 강점

- **부스에서 압도적입니다.** 거대한 것이 비틀거리는 그림은 5m 밖에서도, 아니 20m 밖에서도 보입니다
- 에셋이 극도로 적습니다. 거인 1체 + 배경 몇 개가 전부입니다
- 근접 음성이 필요 없습니다 — 다 같은 조종석 안이라 항상 들립니다. 넷이 동시에 소리칩니다
- 한국 신화 스킨이 자연스럽게 얹힙니다: 장승, 해태, **불가사리**(쇠를 먹는 괴물)

## 리스크 — 정직하게

**기술 난이도가 셋 중 가장 높습니다.** 4인이 분산 조종하는 물리 기반 인체(액티브 래그돌 + IK)는
"넘어지는 게 재밌으려면" 튜닝이 아주 많이 필요합니다. 3.5개월에는 빠듯합니다.

물리 캐릭터 경험이 있는 프로그래머가 있다면 이 안이 임팩트는 가장 큽니다.

# 3안 「탑 TOWER」

> **넷이서 탑을 쌓는다. 그리고 자기가 쌓은 탑 위에 올라가서 더 쌓아야 한다.**

## 익숙한 것 / 신박한 것

| | |
|---|---|
| **익숙** | 블록 쌓기. 세 살도 압니다 |
| **신박** | **자기가 만든 구조물이 자기 발판**입니다. 대충 쌓으면 자기가 죽습니다 |

물이 차오릅니다. 계속 위로 쌓아야 합니다. 무너지면 넷 다 떨어집니다.

## 강점

- **개발 효율이 셋 중 최고입니다.** 블록 몇 종류가 에셋의 전부입니다. 레벨 디자인조차 거의 필요 없습니다
- 실패 전파가 가장 극적입니다. 탑이 무너지는 순간 = 그 자체로 완성된 클립
- 수직성 — PEAK이 증명한 강점을 공유하되 방식이 다릅니다
- "쌓다"는 물리 코옵에서 아직 비어 있는 동사입니다

## 리스크

- 대량 물리 시뮬레이션의 성능/네트워크 동기화가 까다롭습니다
- 비주얼이 밋밋해지기 쉽습니다 → 아트 디렉션에 별도 투자가 필요합니다

## 추천

**「김장」.** 이유는 재미가 아니라 **자리**입니다.

세 안 다 재밌게 만들 수 있습니다. 그런데 김장만이 *"수요는 이미 증명됐는데 아무도 안 만든 조합"* 에
서 있습니다. 2026년 스팀에서는 하루에 70~80개가 쏟아지고 95%가 월 $1,000을 못 법니다.
이 시장에서 실력보다 먼저 결정되는 건 **어디에 서 있느냐**입니다.

**대안**: 물리 캐릭터에 자신 있는 팀이라면 「거신」. 인원이 1~2명으로 아주 적다면 「탑」.

## 다음 단계

어느 안이든 **첫 2주는 회색 박스 프로토타입**입니다.
김장이라면 — 배추 하나, 양념 하나, 미끄러지는 물리. 넷이서 30분 해보고 웃음이 안 나오면 접습니다.
이펙트와 아트는 재미없는 것을 절대 살리지 못합니다.
