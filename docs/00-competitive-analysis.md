# 00. 경쟁 분석

> 목적: "무슨 게임 배꼈다"는 소리를 듣지 않기 위해, **누가 이미 무엇을 점유하고 있는지** 확정하고 우리가 비어 있는 칸에 들어가는지 검증한다.
> 최종 갱신: 2026-08

---

## 1. 결론 먼저

이 시장에는 세 개의 강한 계보가 있고, **세 계보가 교차하는 지점은 비어 있다.**

| 계보 | 대표작 | 우리가 가져올 것 | 우리가 버릴 것 |
|---|---|---|---|
| 규칙 대조 판정 | Papers, Please | 문서/규칙 대조의 인지적 긴장 | 관료제 서사, 도트 아트 |
| 이상 징후 감지 호러 | The Exit 8, I'm on Observation Duty | "뭔가 틀렸다"의 감각 | 반복 복도, 1인칭 이동 |
| 야간 근무 감시 | FNAF | 야간 근무 프레임, 카메라 | 자원 관리, 회피 게임플레이 |

**우리의 새로운 축 하나: 수칙이 플레이어를 속인다.**
Papers, Please의 규칙은 부조리하지만 정직하다. 우리 수칙 중 일부는 **거짓이며, 지키면 죽는다.** 게임의 질문이 "규칙을 잘 지켰는가"에서 **"어떤 규칙을 믿을 것인가"**로 바뀐다. 이것이 익숙함(규칙 대조) 위에 얹는 단 하나의 신선한 축이다.

---

## 2. 직접 경쟁작 상세

### 2.1 The Convenience Store (Chilla's Art) — **가장 위험한 비교 대상**
- 소규모(형제 2인) 일본 개발, PS1풍 저예산 호러, 편의점 야간 근무 소재
- **이미 "편의점 심야 호러"를 점유하고 있다.** 이걸 모르고 만들면 100% 비교당한다.
- **차별화 근거**: Chilla's Art는 1인칭 3D 워킹 시뮬 + 내러티브 호러다. 매장을 걸어다니고, 이야기를 따라간다.
  우리는 **고정 시점 시스템 게임**이다. 이동이 없고, 서사보다 **판정 메커니즘**이 중심이며, 실패가 반복 학습으로 이어진다.
- 액션 아이템: 스토어 페이지·트레일러에서 **"규칙"과 "판정"을 전면에 세운다.** 매장 탐험처럼 보이는 컷을 넣지 않는다.

### 2.2 Papers, Please (Lucas Pope, 2013)
- 규칙 대조 판정 장르의 원형. 서류와 규정집 대조 → 승인/거부.
- **차별화**: (a) 호러 톤, (b) 규칙 자체가 신뢰할 수 없는 정보원, (c) 세션 8~12분의 짧은 루프, (d) 한국 심야 노동 정서.
- 주의: 이 계보의 아류는 매우 많다. "Papers, Please 클론"으로 태깅되는 순간 발견성이 죽는다. **호러 태그를 1순위로.**

### 2.3 The Exit 8 (KOTAKE CREATE)
- 1인 규모, 짧은 분량, 저가. "이상 징후를 찾아라"라는 단일 메커니즘으로 대성공.
- 우리에게 주는 교훈: **단일 메커니즘 + 짧은 분량 + 저가**가 1인 개발의 승리 공식이다.
- **차별화**: Exit 8은 관찰만 한다. 우리는 관찰 후 **응대해야** 하고, 응대에 사회적 압박(손님이 재촉한다)이 붙는다.

### 2.4 Five Nights at Freddy's
- 야간 근무 + 감시 카메라 프레임의 원조. **비교를 피할 수 없으므로 정면으로 다르게 만든다.**
- FNAF: 자원(전력) 관리 + 위협 회피. 플레이어는 **막는다**.
- 우리: 정보 수집 + 판정. 플레이어는 **판단한다**. CCTV는 위협 감시가 아니라 **증거 수집** 도구다.
- 액션 아이템: "문을 닫아 막는" 메커니즘을 절대 넣지 않는다. 넣는 순간 FNAF 아류가 된다.

### 2.5 I'm on Observation Duty 시리즈
- 초저예산 CCTV 이상 징후 감지. 저가·다작 전략.
- **차별화**: 순수 관찰 게임이며 서사·판정·캐릭터 상호작용이 없다. 우리는 손님과의 상호작용이 코어다.

### 2.6 규칙괴담(Rule-based horror) 장르 전반
- "이 장소의 규칙 목록을 지켜라" 형식은 최근 한중 웹 괴담에서 크게 유행했고 인디 게임으로도 다수 파생됨.
- **기회**: 유행 중이라 관객이 문법을 이미 안다 = 익숙함 확보.
- **위험**: 후발 포화. 단순 "규칙 지키기"만으로는 차별화가 안 된다. → 우리의 "거짓 수칙" 축이 필수인 이유.

## 3. 포지셔닝 맵

```
                    관찰만 함
                        │
      I'm on Obs. Duty  │  The Exit 8
                        │
  서사 약함 ────────────┼──────────── 서사 강함
                        │
      ★ NIGHTSHIFT      │  Chilla's Art
      Papers, Please    │  FNAF
                        │
                   판정·응대함
```

우리가 노리는 칸: **판정·응대 × 서사 약함(시스템 중심)** + 호러 톤.
이 칸의 기존 강자는 Papers, Please 하나뿐이고, 그건 호러가 아니다.

## 5. 검증되지 않은 가정 (⚠ 반드시 확인할 것)

이 문서의 경쟁작 정보는 시장 리서치와 일반 지식 기반이다. **개발 착수 전 직접 확인하라:**

- [ ] Steam에서 `호러` + `시뮬레이션` 태그 조합 신작을 직접 훑어 최근 6개월 내 유사작이 나왔는지 확인
- [ ] "편의점 호러", "convenience store horror", "rule horror game" 검색으로 후발 경쟁작 점검
- [ ] 위 경쟁작들의 **최신 판매·리뷰 수치**를 SteamDB/VG Insights에서 재확인 (본 문서 수치는 추정)
- [ ] 각 경쟁작을 **실제로 1시간씩 플레이**한다. 리뷰 요약으로 대체하지 말 것.

> 경쟁 분석은 한 번 쓰고 끝내는 문서가 아니다. Steam 페이지 오픈 직전에 반드시 한 번 더 갱신한다.
