# GameProject1 — 게임 기획 저장소

시장 조사와 컨셉 검증 기록입니다. **아직 확정된 게임은 없습니다.**
지금까지 네 개의 안을 만들었고 네 개 다 폐기했습니다. 폐기 과정에서 나온 것들이 이 저장소의 내용입니다.

---

## 지금까지 알아낸 것

### 1. 시장은 극단적으로 양극화돼 있다

스팀에 **하루 70~80개**가 나오고 **95%가 월 $1,000을 못 법니다.**
같은 시장에서 PEAK은 개발비 $200,000 미만으로 **1,000만 장**, R.E.P.O.는 **1,600만 장**을 팔았습니다.
중앙값은 처참하고 상위는 폭발합니다. **중간이 없습니다.**

### 2. 미래에 살아남는 구조는 하나다

다섯 개의 시장 축(공급 폭발 · 디스커버리 붕괴 · AI · 라이브서비스 붕괴 · 플랫폼 이동)이
전부 같은 곳을 가리킵니다:

> **콘텐츠가 개발자에게서 오지 않고 플레이어들 사이에서 발생하는 게임.**

AI가 무엇이든 무한 생성하는 시대에 유일하게 복제 불가능한 것은
**"내 친구와 나 사이에서 방금 벌어진 일"** 이기 때문입니다.

### 3. 그런데 그 1세대(프렌드슬롭)는 이미 포화다

물리 코옵으로 떠올릴 수 있는 소재를 전수 검색했습니다. **예외 없이 전부 있었습니다.**
등반·운반·숨바꼭질·소방·추락기·심해·무중력·하이스트·던지기 — 전부 선점됐습니다.

### 4. 그래서 접근을 뒤집어야 한다

```
❌ 소재를 정하고 → 메커니즘을 붙인다        (전부 충돌)
✅ 메커니즘을 발명하고 → 소재는 흔한 걸 쓴다   (실제로 뚫은 방식)
```

MECCHA CHAMELEON은 **숨바꼭질**이라는 세상에서 제일 흔한 소재로 첫 주 100만 장을 팔았습니다.
새로웠던 건 소재가 아니라 `붓으로 자기 몸을 칠해 배경에 섞인다`는 **메커니즘 하나**였습니다.

## 검증 기준 — 다음 안은 이걸 전부 통과해야 한다

### 설계 5법칙 ([SIMULATION.md](docs/SIMULATION.md))

1. 목표가 항상 화면에 보인다
2. 되돌릴 수 없는 손실이 있다
3. 혼자서도 유용한 일을 할 수 있다
4. 실패해도 진행의 일부는 남는다
5. 조작은 "잡기" 하나로 전부 표현된다

### 미래 적합성 8문항 ([MARKET_FUTURE.md](docs/MARKET_FUTURE.md))

콘텐츠가 플레이어 사이에서 발생하는가 · 30초 클립이 저절로 나오는가 · 매 세션이 다른가 ·
친구를 데려오는가 · 1시간 안에 완결되는가 · 저사양에서 도는가 · 사람이 만들었음이 느껴지는가 ·
**판타지와 위험이 있는가**

마지막 문항이 「김장」을 죽였습니다. 앞의 7개를 전부 통과했는데도 재미가 없었습니다.
**성공한 프렌드슬롭은 전부 "하면 안 되는 일" 아니면 "무서운 일"입니다.**

## 일정에 대한 현실 판단

지스타 2026은 **11월 19~22일**이고 **일반 부스 신청은 7월 31일에 마감**됐습니다.
남은 기간은 약 3개월입니다.

**새 메커니즘을 발명해서 3개월 안에 검증까지 하는 건 현실적이지 않습니다.**
포화한 시장에 급하게 낸 아류는 95% 구간으로 직행합니다.

권장: 지스타 2026을 목표에서 내리고 **메커니즘 검증에 시간을 씁니다.**
제대로 된 메커니즘 하나가 있으면 지스타 2027도 스팀 단독 출시도 전부 열립니다.
