# GameProject1 — 지스타 출품 게임 기획

2026년 스팀 시장 조사에서 역산한 게임 컨셉 저장소입니다.

## 조사에서 나온 결론

2026년 스팀은 하루 **70~80개**가 출시되고 그중 **95%가 월 $1,000을 못 법니다.**
그런데 같은 시장에서 PEAK은 **개발비 $200,000 미만으로 1,000만 장**, R.E.P.O.는 **1,600만 장**을 팔았습니다.

중앙값은 처참하고 상위는 폭발합니다. **중간이 없습니다.**

그 상위권을 관통하는 공식은 하나였습니다:

```
누구나 아는 동사  +  그걸 마음대로 못 하게 만드는 물리
                 +  실패가 팀 전체에 전파되는 구조
                 +  3~4인 & 근접 음성  +  $8~20
```

「신박한데 익숙한」의 정체가 이겁니다.
**PEAK**은 *오르다*에, **R.E.P.O.**는 *옮기다*에, **MECCHA CHAMELEON**은 *숨다*에 비틀기를 하나씩 넣었습니다.

### 추천은 「김장」이고, 이유는 재미가 아니라 자리입니다

K-소재 게임은 이미 스팀에서 통하고 있습니다 — 김밥천국 시뮬, 포장마차, 한국 BBQ 시뮬.
그런데 **전부 혼자 하는 힐링 시뮬**입니다.

**K-소재 × 4인 물리 카오스 코옵은 아직 아무도 안 만들었습니다.**
수요는 증명됐고 교집합은 비어 있습니다.

그리고 시각적으로 — 게임이 진행될수록 **화면이 하얀색에서 빨간색으로 물듭니다.**
유튜브 썸네일과 스팀 스크린샷이 저절로 만들어집니다.
