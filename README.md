# GameProject1 — 「일섬 ISSEN」 (가제)

> 몰려드는 적을, 단 한 번의 칼질로 전부 벤다.

지스타 출품 + 스팀 출시를 목표로 하는 **쿼터뷰 스코어어택 액션** 게임의 기획 저장소입니다.

## 한 줄 요약

**조작은 스틱 + 버튼 1개.** 적을 유인해 한 덩어리로 뭉친 뒤, 완벽한 순간에 발도해서 화면을 통째로 갈라버리는 게임.

## 왜 이 컨셉인가

| 요구사항 | 이 게임의 답 |
|---|---|
| 조작을 금방 익힌다 | 버튼이 **1개**다. 설명 3초: "빨간 빛 뜨면 눌러. 많이 모아서 한 번에." |
| 퍼포먼스가 있다 | 20마리를 한 번에 베면 화면이 대각선으로 갈라진다. 5m 밖에서도 보인다. |
| 부스에서 줄이 선다 | 실력 차이가 "몇 마리를 한 방에 베었나"로 **눈에 보인다**. 관전자가 "지금! 눌러!" 하고 소리치게 된다. |
| 스팀에서 팔린다 | 로그라이트 런 구조 + 무기별 발도 패턴 + 데일리 리더보드. 8~15시간 분량, $12~15. |
| 3.5개월에 만든다 | 3색 팔레트 실루엣 아트. 모델러 없이 프로그래머 + TA로 완성 가능. |
